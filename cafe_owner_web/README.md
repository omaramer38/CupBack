# CupBack Cafe Owner Web (Prototype)

واجهة أولية مستقلة لبوابة صاحب الكافيه، مبنية بـ React وVite. تشمل التنقل بين أقسام المالك، لوحة مبيعات تجريبية، الطلبات، المنيو، العملاء والخصومات الفردية، الولاء، الموظفين، الرواتب الشهرية النقدية، تخصيص صفحة الكافيه، تقارير المبيعات، والإعدادات.

## التشغيل

```bash
npm install
npm run dev
```

## حالة البيانات

هذه نسخة واجهة تجريبية تستخدم بيانات ثابتة وحالة محلية في المتصفح. التغييرات لا تصل إلى تطبيق Flutter أو قاعدة بيانات. لا يوجد Backend في المستودع حاليًا؛ يلزم اعتماد وتطوير API موحد قبل استخدام الدخول والرواتب والخصومات والمظهر في الإنتاج. لا تضع بيانات مالية حقيقية في النسخة الحالية.

## التقنية

- React + Vite.
- Cairo للعربية وPlus Jakarta Sans للإنجليزية والأرقام.
- RTL افتراضي، مع تخطيط متجاوب.

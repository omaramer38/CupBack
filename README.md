## 🚀 التشغيل السريع (Quick Start)

### تشغيل التطبيق بضغطة زر:
اضغط مرتين على الملف:
```cmd
run_app.bat
```

### أو عبر سطر الأوامر:
```bash
cd cupback_mobile
flutter run
```
